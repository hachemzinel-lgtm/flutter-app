NEARWORK PROJECT TECHNOLOGIES & APIs

=============================================================================
1. CORE STACK
=============================================================================
- Framework: Flutter ^3.11.1
- Language: Dart (Null-safe)
- Design: Material 3 Design
- State Management: flutter_riverpod ^3.3.1
- Navigation: go_router ^13.0.0

=============================================================================
2. BACKEND SERVICES (FIREBASE)
=============================================================================
- Firebase Auth: Secure user authentication (Email/Password & Social).
- Cloud Firestore: Scalable NoSQL database for users, services, and chats.
- Firebase Storage: Cloud storage for profile pictures, PDFs, and media.
- Firebase Messaging (FCM): Cloud-to-device push notifications.
- Firebase App Check: Device integrity and API protection.

=============================================================================
3. EXTERNAL APIs & INTEGRATIONS
=============================================================================
- Google Sign-In API: Native Google authentication integration.
- Groq Cloud API: High-speed AI inference for Llama 3 and Mixtral models.
- OpenStreetMap: Open-source map tile integration via flutter_map.
- Google Geocoding API: Address-to-coordinate and reverse lookup services.
- Device Location (GPS): Real-time user position tracking via Geolocator.

=============================================================================
4. KEY LIBRARIES & COMPONENTS
=============================================================================
- Typography: Google Fonts (Inter, Outfit).
- Icons: Lucide Icons (Lucide_icons package).
- Chat UI: Dash Chat 2 (Standardized chat interface).
- Local Storage: Flutter Secure Storage (Sensitive data encryption).
- Connectivity: Connectivity Plus (Real-time network status monitoring).
- Audio: Audioplayers & Record (Voice messaging and playback).
- PDF Support: Syncfusion PDF Viewer & Read PDF Text.
- Images: Cached Network Image & Image Picker.

=============================================================================
5. DEV TOOLS
=============================================================================
- Environment: flutter_dotenv (.env configuration).
- Linting: flutter_lints ^6.0.0.
- Testing: flutter_test.
=============================================================================
